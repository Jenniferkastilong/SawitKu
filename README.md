Branch untuk uts adalah 'UTS'

Aplikasi memiliki 3 role utama yaitu Petani, Pengurus, dan Admin. Semua role dapat melakukan registrasi dan login akun yang akan masuk firestore database.

Petani
1. Setelah login petani diminta untuk Setup Profil -- sudah, tapi masih error untuk menyimpan foto
2. Petani dapat melaporkan lahan mereka ke pengurus/konsultan -- sudah
3. Petani dapat melihat riwayat laporan dan dapat mengedit maupun menghapus laporan jika belum diverifikasi oleh pengurus -- sudah
4. Petani dapat mengedit profil dan tersimpan di firebase -- sudah

Pengurus/Konsultan
1. Dapat melihat semua laporan lahan yang diberikan petani -- sudah
2. Dapat memverifikasi dan akan muncul di admin -- sudah
3. Dapat meminta revisi -- sudah, tapi belum bisa mengisi input revisi apa yang diminta

Admin
1. Dapat mengelola semua akun user (petani, pengurus, bahkan admin) dengan menonaktifkan akun bahkan menghapus akun dan otomatis data user akan hilang dari firestore database -- sudah
2. Dapat melihat laporan lahan petani setelah diverifikasi oleh pengurus -- sudah
3. Dapat melihat detail laporan -- sudah
4. Dapat memverifikasi laporan petani jika disetujui -- sudah tapi masih dalam proses perkembangan
5. Dapat mendownload foto lahan jika foto tersebut dapat terkirim dengan baik -- sudah
6. Dapat mendownload file PDF dan CVS -- sudah
